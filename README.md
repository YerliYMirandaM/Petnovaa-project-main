 PET NOVA

 About the Project

PET NOVA is a website created to help pet owners find useful information and tools for taking care of their pets. We wanted to create a space that is easy to use, helpful and also reflects the special bond between people and their pets.

eatures

- Home: Introduces the website and its main purpose.
- Functions: Includes examples of different tools designed for pets and their owners.
- About Us: Explains the project, what we wanted to achieve, our values and the team behind it.
- Contact Us: Provides ways to contact the team.
- login: Includes a user account section.

 Design

We wanted PET NOVA to have a friendly and welcoming look. The website uses colors, images and interactive elements to make it more enjoyable and easy to explore.
